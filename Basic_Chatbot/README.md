# CodeAlpha Basic Chatbot

## Project Description

This project is a simple rule-based chatbot developed using Python.

The chatbot interacts with the user through the terminal and provides responses to common questions and greetings.

## Features

- Responds to greetings such as hello, hi, and hey
- Responds to "How are you?"
- Tells the chatbot's name
- Explains what it can do
- Provides a basic explanation of Python
- Responds to help requests
- Responds to thanks and thank you
- Supports exit commands such as bye, exit, and quit
- Handles unknown inputs

## Technologies Used

- Python
- VS Code

## How to Run

1. Open the project folder.
2. Open `chatbot.py`.
3. Open the terminal.
4. Run:

```bash
python chatbot.py
