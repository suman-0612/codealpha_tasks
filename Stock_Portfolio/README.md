# CodeAlpha Stock Portfolio Tracker

## Project Description

This project is a simple Stock Portfolio Tracker developed using Python.

The program allows users to enter stock symbols and the number of shares they own. It calculates the investment value of each stock and the total value of the portfolio.

## Features

- Stores sample stock prices
- Allows users to enter stock symbols
- Allows users to enter the number of shares
- Checks whether the stock is available
- Calculates investment value for each stock
- Allows multiple stocks to be added
- Validates that the quantity is greater than zero
- Displays the complete portfolio
- Calculates the total portfolio value

## Technologies Used

- Python
- VS Code
